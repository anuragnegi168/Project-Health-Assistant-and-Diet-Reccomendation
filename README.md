# Project Health Assistant

A Streamlit-powered AI health and nutrition assistant that calculates key health metrics and provides personalized diet recommendations using a retrieval-augmented generation (RAG) workflow.

## Overview

This application helps users:

- calculate BMI, BMR, TDEE, and calorie targets
- receive a simple personalized diet plan based on age, gender, weight, height, activity level, and dietary preferences
- ask health and nutrition questions through an AI assistant
- use a local vector database built from nutrition content for context-aware responses

The app is designed for general wellness guidance and educational purposes, not medical diagnosis or treatment.

## Features

- User profile input via sidebar
- BMI, BMR, TDEE, and calorie target calculations
- Diet recommendation tab with AI-generated meal suggestions
- Health Q&A assistant powered by a nutrition knowledge base
- RAG-based document retrieval using FAISS and sentence-transformers
- Streamlit UI for quick interaction

## Tech Stack

- Python
- Streamlit
- LangChain
- FAISS
- Hugging Face embeddings
- OpenAI-compatible API via Hugging Face router
- PyPDF for PDF knowledge ingestion

## Prerequisites

- Python 3.9+
- A Hugging Face access token for the OpenAI-compatible inference endpoint
- A valid `data/nutrition.pdf` file for RAG context

## Setup

1. Clone or open the project folder.
2. Create a virtual environment (optional but recommended):

```bash
python -m venv env
```

3. Activate the environment:

- Windows:

```bash
env\Scripts\activate
```

- Linux/macOS:

```bash
source env/bin/activate
```

4. Install dependencies:

```bash
pip install -r requirements.txt
```

5. Create a `.env` file in the project root with your Hugging Face token:

```env
HF_TOKEN=your_huggingface_token_here
```

6. Build the vector database:

```bash
python create_database.py
```

If the `data/nutrition.pdf` file is present, this creates the FAISS vector store under `vector_db/`.

## Run the App

Start the Streamlit application:

```bash
streamlit run app.py
```

Then open the local URL shown in the terminal (typically `http://localhost:8501`).

## How It Works

1. The user enters health details through the sidebar.
2. The app calculates BMI, BMR, TDEE, and calorie target using formulas in `diet.py`.
3. The RAG pipeline loads nutrition knowledge from `data/nutrition.pdf` and stores chunked content in FAISS.
4. The user can either:
   - generate a diet plan based on the entered profile, or
   - ask a health-related question
5. The LLM receives the retrieved context and a prompt to generate a helpful nutrition response.

## Troubleshooting

### Error: "RAG is not connected"

This usually means the vector database was not created or the `vector_db` folder is missing.

Run:

```bash
python create_database.py
```

### Missing environment variables

Ensure your `.env` file exists and contains a valid `HF_TOKEN` value.

### Model access issues

Check that your Hugging Face token is valid and that the endpoint route used by the app is accessible.
